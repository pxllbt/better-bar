# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Better Bar, please report it responsibly:

1. **Do not open a public issue.**
2. Send an email to the repository maintainer via their GitHub profile or open a private advisory at [GitHub Security Advisories](https://github.com/pxllbt/better-bar/security/advisories/new).
3. Include detailed steps to reproduce the issue and any relevant system logs.

We appreciate your efforts in keeping Better Bar safe for all users.
